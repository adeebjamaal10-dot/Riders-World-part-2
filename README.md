# The Rider's Passport
**The International Atlas of Equestrian Destinations, Culture & History**  
*An International Equestrian Publication Supported by Sorenta Saddlery (Official Research Partner)*

> "Explore the World Through the Eyes of a Rider."

---

## 📖 Overview

**The Rider's Passport** is a turnkey, evergreen educational atlas and cultural publication featuring **300 documented equestrian profiles** across 50 countries, spanning over 5,500 years of horsemanship heritage.

- **50 International Equestrian Country Guides**: National equine history, heritage breeds, state riding traditions, and cultural governance.
- **100 Historic & Scenic Destinations**: Natural landscapes shaped by riding, from the Camargue delta to the Icelandic volcanic valleys.
- **100 Heritage Landmarks & Institutions**: Ancient royal riding academies (Vienna, Saumur, Jerez, Queluz), historic stud farms, and classical arenas.
- **50 History Archive Milestones**: In-depth documentary accounts of Olympic milestones, founding sporting rules, and classical treatises from 3500 BCE to the modern era.
- **Interactive Calibrated World Atlas**: Equirectangular projection mapping pins across every continent with Nocturne (Black & Gold) and Parchment modes.
- **Official Research Partner**: [Sorenta Saddlery](https://sorenta-saddlery.com/) — Championing master saddlery craftsmanship, anatomical tree engineering, equine welfare, and heritage preservation.

## 🚀 Cloudflare Pages & GitHub Deployment Guide

This project is pre-configured for direct, zero-friction deployment to **Cloudflare Pages** connected to your **GitHub** repository.

### Step 1: Connect & Push to GitHub

1. Create a new repository on [GitHub](https://github.com/new) (e.g. `the-riders-passport`).
2. In your local terminal inside this project directory, initialize and push:
```bash
git init
git add .
git commit -m "feat: Initial commit of The Rider's Passport"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/the-riders-passport.git
git push -u origin main
```

---

### Step 2: Deploy on Cloudflare (Workers & Pages via GitHub)

1. Log into your [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Navigate to **Workers & Pages** > **Create application**.
3. Select your GitHub repository (`Riders-Passport-` or `the-riders-passport`).
4. Build settings are pre-configured:
   - **Framework Preset**: `Vite` (or `None`)
   - **Build command**: `npm run build`
   - **Deploy command**: `npx wrangler deploy` *(supported automatically via `wrangler.toml` assets)*
   - **Build output directory**: `dist`
5. Click **Save and Deploy** (or click **Retry build** on your current deployment).

Cloudflare will automatically:
- Run `npm run build` to generate the production bundle in `dist/`.
- Run `npx wrangler deploy` which reads all 25 files from `./dist` via the `[assets]` configuration in `wrangler.toml`.
- Configure SPA client routing (`not_found_handling = "single-page-application"`).
- Publish your site globally on Cloudflare edge CDN with instant SSL.

---

### Alternative: Instant CLI Deployment via Cloudflare Wrangler

If you prefer to deploy directly from your command line without connecting GitHub:

```bash
# 1. Build the production bundle
npm run build

# 2. Deploy directly to Cloudflare Pages
npx wrangler pages deploy dist --project-name=the-riders-passport
```

## 📁 Repository Structure & Cloudflare Files

All files are structured in standardized locations required for Cloudflare Pages:

```text
├── public/
│   ├── _headers          # Cloudflare Edge CDN cache control & security headers
│   ├── _redirects        # Cloudflare SPA routing rewrite (/* -> /index.html 200)
│   ├── favicon.svg       # Luxury gold & obsidian equestrian crest favicon
│   ├── robots.txt        # Public search engine discovery & SEO configuration
│   └── assets/
│       ├── aistudio/     # User photography, outline world map, and sponsor crest
│       └── images/       # High-fidelity classical equestrian photography
├── src/
│   ├── components/       # Modular UI components (Atlas, Timeline, Modals, Navbar, etc.)
│   ├── data/             # Complete 300-profile database, historical milestones, and assets
│   ├── types/            # TypeScript interfaces for equestrian profiles and continents
│   ├── App.tsx           # Primary application view manager
│   ├── main.tsx          # React 19 entry point
│   └── index.css         # Tailwind CSS luxury black & white theme variables
├── dist/                 # Production output directory generated by 'npm run build'
├── wrangler.toml         # Cloudflare Pages deployment configuration
├── vite.config.ts        # Vite configuration with base path & alias setup
├── package.json          # Dependencies & build scripts (engines: node >= 18.0.0)
└── tsconfig.json         # Strict TypeScript configuration
```
